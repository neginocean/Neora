The modular foundation platform powering Neora Studio websites.

== Description ==

Neora Core is the internal engine behind Neora Studio’s website projects.

It provides a clean, modular WordPress-native architecture that separates

business logic from presentation, enabling multiple themes and visual

presets to connect to the same reliable core.
